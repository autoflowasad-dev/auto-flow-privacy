Privacy Policy — Auto Flow

Extension: “Auto Flow — batch prompts for Google Flow”. Developer: Muhammad Asad. Last updated: 12 September 2026.

Short version

Auto Flow does not collect, transmit or sell any personal data. It has no servers, no accounts and no analytics. Everything you put into it stays inside your own Chrome profile on your own computer.

What the extension stores, and where

  • Your prompts, run progress and activity log — stored locally with chrome.storage.local so a run can be paused, resumed and reviewed.
  • Your settings (folder name, file-name prefix, model, aspect ratio, clip length, download quality, delays) — stored locally.
  • Reference pictures you add — stored locally so they can be attached to prompts and, when needed, uploaded to your own Google Flow project by you through the extension.

None of this is sent anywhere. You can delete all of it at any time by removing the extension, or by using “Reset all settings” and “Clear list” inside the extension.

The e-mail you enter to activate

Auto Flow is free for the first 20 prompts. To continue, you enter an e-mail address once.

  • What is sent: the e-mail address you type, a random install id generated on your computer, the extension version, and the date.
  • Where it goes: to the developer's own Google Sheet, through a Google Apps Script endpoint at script.google.com. Chrome asks your permission before the first send; if you decline, the extension still unlocks and nothing is sent.
  • Why: to know who is using Auto Flow and to be able to contact you about updates or problems.
  • What is not sent: your prompts, your pictures, your generated videos or images, your settings, your Google account details, or anything from other websites.
  • Sharing: the address is not sold, rented or shared with anyone else, and is not used for advertising.
  • How long: it is kept while the extension is in use. To have it removed, e-mail the address in the Contact section and it will be deleted from the sheet.
  • On your computer: the same address is stored locally so the extension knows it is activated. Removing the extension removes that copy.

Usage counts

Auto Flow counts how many prompts you sent to Google Flow and how many files it saved, per day. You can see these numbers yourself under Settings → Your usage.

  • What is sent, once activated: for each finished day, the date and two numbers (prompts sent, files saved), together with your activation e-mail, the install id and the extension version. The current day is never sent while it is still running.
  • Where it goes: the same Google Sheet as the activation, through script.google.com, and only if you allowed that when you activated.
  • Why: so the developer knows how much Auto Flow is actually used and can plan updates.
  • What is never sent: your prompt text, your reference pictures, your generated videos or images, file names, your settings, or anything about other websites you visit.
  • Before activation (the free trial) nothing is sent at all.

Network activity

The extension makes no network requests of its own. It only acts inside the Google Flow page (flow.google.com, labs.google) that you have already opened and signed into, in the same way you would by clicking there yourself. Files are saved with Chrome’s own downloads feature to your Downloads folder.

Data we do not handle

Auto Flow does not read or store your Google account credentials, your mailbox, your browsing history, or any data from other websites. Apart from the one-time activation request described above, it has no access to any site other than Google Flow.

The debugger permission

Auto Flow declares Chrome's debugger permission because Google Flow's prompt box sometimes refuses ordinary typing. If you switch Settings → Flow page → Typing (or Generate) to a “Debugger” option, keystrokes and clicks are sent to your Flow tab that way, and only while a run is active; Chrome shows a “started debugging this browser” bar during that time and the connection is closed when the run ends. Nothing on the page is read, stored or transmitted. Chrome does not allow this permission to be optional, so it appears in the install list even if you never switch those options on.

Optional permissions

  • power — only if you tick “Keep the computer awake while a run is going”.
  • notifications — only if you tick “Show a notification when a run ends”.

Chrome asks you before granting any of these, and you can revoke them at any time on chrome://extensions.

The “Record Flow clicks” tool

This optional troubleshooting tool writes a file to your Downloads folder describing which buttons were clicked on the Flow page, so a broken step can be diagnosed. It deliberately excludes your prompt text, media links and e-mail addresses. The file is never uploaded; you decide whether to share it.
