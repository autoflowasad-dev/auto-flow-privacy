Auto Flow

batch prompts for Google Flow

Auto Flow runs your whole prompt list on Google Flow while you do something else. Paste your prompts, press Start, and each result is saved to your Downloads folder with a numbered file name — 001.mp4, 002.mp4, 003.mp4 — so a long series stays in order.

Getting started

  1. Open your Google Flow project in a tab.
  2. Open the Auto Flow side panel (toolbar icon, or Alt+Shift+F).
  3. Paste your prompts, or import a .txt / .csv file.
  4. Under Flow settings choose the model, aspect ratio, clip length and results per prompt. “Keep” leaves Flow as it is.
  5. Press Start.

Reference pictures

Open the Pictures tab and add your character or location images. Then choose how they are matched:

  • In list order — 1st picture goes with the 1st prompt, 2nd with the 2nd, and so on.
  • By the number in the file name — 026.jpg goes with Prompt 26.
  • Every prompt — tick a picture to use it in all prompts.
  • Inside a prompt: [REF: hero.jpg], frames [START: a.png] [END: b.png], and [SETTINGS: 9:16, 10s, x2] for that prompt only.

Free trial

The first 20 prompts are free. After that, enter an e-mail address once in the panel to keep using it — no password and no verification e-mail. Your prompt list is never lost when the trial ends.

Common questions

Auto Flow says “Open Google Flow in this tab”.
Click that button — it loads Flow in the current tab. Auto Flow only works on a Google Flow page.

Nothing happens when a prompt is sent.
Open Settings → Flow page → Check page. The prompt box should be highlighted green and the Generate button blue. If not, use the Pick buttons.

A file was not saved.
After the run press Save missing files with the same Flow project open. The Activity tab always shows the reason.

The run stopped by itself.
Flow reported a credit or rate limit, or the page was reloaded. Your list is kept — press Resume.

Google Flow changed and a step broke.
Settings → Teach Auto Flow → Record Flow clicks, do that step once by hand, press Stop, and e-mail the saved file to the address below.
